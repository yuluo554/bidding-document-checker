## 一、合成数据设计

### 1.1 文档体例（v1 输入格式）

生成器产出 **Markdown 固定体例**纯文本文档（决策 D7）：

- **招标文件**（单份）：第一章 招标公告 → 第二章 投标人须知（含前附表）→ 第三章 评标办法
  （含分值构成表）→ 第四章 合同条款 → 第五章 技术要求（含 ★/▲ 星号条款）→ 第六章 投标文件格式；
- **投标文件**（每项目 N=3~5 份）：第一章 投函声明 → 第二章 资格证明文件（证书清单+有效期）
  → 第三章 商务偏差表 → 第四章 技术方案（含星号条款响应）→ 第五章 开标一览表与分项报价
  （大小写金额）→ 第六章 承诺函 → 第七章 拟投入人员与类似业绩清单；
- 主体全部虚构：招标人/代理/投标人名称池（"华信达项目管理有限公司"类合成名）、人名池、
  证书编号池（`CERT-2026-XXXX` 合成格式）、项目名池（货物类/服务类场景）。

### 1.3 数据目录与台账

```
data/
├── README.md          # 台账：每份数据登记来源/许可/status（已有骨架）
├── knowledge/         # 法规三层（raw/ + blocks.jsonl + rules.json）
├── samples/           # 生成器产出的演示项目包（固定 seed，入仓 examples/ 由生成器再生成）
└── _private/          # 不入仓
生成器代码：src/bidchecker/datagen/（随包分发、带测试；`bidchecker datagen` 可再生成）
```

### 1.4 真值语义（一次定清，生成器模块注释同步）

- `ground_truth.json` 随项目包输出：`expect_findings: [{defect_id, rule_type, target, risk_level}]`
  + `also_expect: [...]`（同一注入隐含的其余结论）+ `clean: bool`（无注入对照组）；
- 端到端基准按"文档全部非 pass 集合"对账：注入缺陷必检出不漏报；干净对照零误报；
- **互斥坑当场记录**（写入生成器模块注释）：同一参数两处注入打架（如 D6 与 D7 同表冲突）→
  生成器按项目内互斥表排布；多值字段封顶规则；先清旧行再注入。

## 二、法规知识库获取计划

| 优先级 | 法规 | 渠道（fallback 顺序） | 用途 |
|---|---|---|---|
| 1 | 财政部令第 87 号（政府采购货物和服务招标投标管理办法） | 财政部官网 → 中国政府网 → 国家法律法规数据库 | 否决情形、资格条件设置依据 |
| 2 | 招标投标法 + 实施条例（613 号令，含 39/40 条） | 国家法律法规数据库 flk.npc.gov.cn → 中国政府网 | 围标情形、基本原则条款 |
| 3 | 发改委等 8 部门令第 16 号（公平竞争审查规则） | 国家发改委官网 | 资格条件不合理情形 |
| 4 | 发改法规〔2026〕195 号（AI 推广实施意见） | 国家发改委官网 | 背景政策（README/报告引用） |

- 每条入库：`raw/` 存原文 + 台账登记 URL/获取日期/sha256/status；
- 下载渠道 fallback：官方 API > ghproxy/镜像 > raw 直连，逐文件重试+校验（大小/魔数）；
- **搜索通道污染防御**：WebSearch 摘要一律不采信，只用可直连官方页面原文核验；两渠道查不到 →
  status=待核对 + 继续推进，不编造不停摆；
- 结论引用链：Finding.basis → blocks.jsonl {law, article_no} → 原文锚点（报告可溯源）。

## 四、风险与对策

| 风险 | 对策 |
|---|---|
| 法规条文官方原文获取失败 | status=待核对继续推进；规则以招标文件条款出处为主；两渠道失败即降级，不空转 |
| v1 只支持 Markdown 体例被质疑实用性 | README 限制节如实声明；docx 适配为缓议加分项（06 D7）；生成器体例即"标准输入接口" |
| 缺陷注入之间互相污染真值 | 项目级互斥表 + 真值语义"主期望+also_expect 全集合对账" |
| 时间超支 | 每周可演示物先行；M5 加分项（围标图谱/文档 docx 固化）可在 DoD 达成后再增强 |
| Windows 环境 pyc/编码随机故障 | 全程 PYTHONDONTWRITEBYTECODE=1 + py -X utf8 + 分批测试；连续失败才深挖（crash-loop-rescue 阶梯） |
