## 二、FR 功能清单

### FR-1x 输入与解析（P0）

| id | 需求 | 验收口径 |
|---|---|---|
| FR-11 | 招标文件解析：公告、投标人须知、评标办法、合同条款、技术要求 → 采购需求参数卡（资格条件清单、星号条款、评标办法与分值、保证金、关键时间节点、否决条款清单） | 生成器真值上字段级 F1 ≥ 0.95 |
| FR-12 | 投标文件解析：资格证明、商务偏差表、技术方案、开标一览表/报价明细、承诺函、人员证书清单 → 投标响应参数卡 | 同上 |
| FR-13 | 解析器规则优先：正则+槽位+合法性校验（数值超范围即丢弃）；LLM 仅对规则抽取失败的槽位兜底（FR-45） | 基准全程零 API 依赖可重复 |

### FR-2x 统一中间表示（P0）

| id | 需求 | 验收口径 |
|---|---|---|
| FR-21 | 参数卡 schema（v1）：条款-要求-约束类型-证据{章节，原文摘录}，JSON 可序列化，带 schema_version | schema 定稿入 [04-模块详设.md](04-模块详设.md) §1；变更需同步真值语义并重跑基准 |
| FR-22 | 每个抽取字段携带证据（章节定位 + 原文逐字摘录） | 证据摘录必须是原文子串 |

### FR-3x 符合性校核引擎（P0，核心）

| id | 需求 | 验收口径 |
|---|---|---|
| FR-31 | 资格条件逐项比对：缺失/过期/等级不足 → 不符合（风险分级），挂 87 号令或招标文件条款出处 | 植入缺陷检出率 ≥ 0.95 |
| FR-32 | 星号条款响应校核：逐条核验响应位置与内容偏差 | 同上 |
| FR-33 | 算术复核：开标一览表大小写金额一致、分项合计=总价；时间逻辑：投标有效期覆盖评标+合同周期、保证金金额与形式 | 数值类结论误报 = 0 |
| FR-34 | 否决项扫描：对照否决条款清单逐项排查并输出命中证据 | 同上 |
| FR-35 | 结论三级判定：符合 / 不符合（高/中/低风险）/ 待人工确认；多值与低置信度不硬判 | 每条非"符合"结论必须挂依据；依据关联率 100% |
| FR-36 | 类目隔离门控：货物类/服务类规则按关键词门控，门控对全部 check_type 生效 | 门控单测（含 conditional/checklist 分支） |

## 三、边界与非目标（防 scope 失控）

承接 [01 §六](01-题目详细定义.md)，并细化：

1. **不做**真实投标数据——全部合成（公司名/人员/证书编号虚构），`data/**/_private/` 不入仓；
2. **不做**授标或报价决策建议——定位"辅助评审定位，非评标决策工具"，报告与 README 带免责声明；
3. **不做**电子交易平台对接、CA/签章、开评标流程管理；
4. **不做** PDF/扫描件 OCR（v1 输入为生成器产出的 Markdown 固定体例；docx 适配为缓议加分项，见 [06-决策记录.md](06-决策记录.md) D7）；
5. **不做**评标打分——符合性校核≠评标分值计算（评标办法只抽取分值构成作上下文）；
6. **不做**多语言（中文公共采购场景）；
7. **围标分析仅限文本特征**，不做股权/人员等隐私关联；
8. **LLM 不可用必须可全流程跑通**——规则通路独立完整，LLM 为可关停的可选增强；
9. **品牌隔离**：不复制姊妹项目代码，文档不提建造/电力/医疗业务。
