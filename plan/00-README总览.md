## 里程碑（初稿）

- M1 数据先行：招标文件模板（货物/服务类）+ 投标文件模板（N份/项目）+ 生成器（带真值/植入缺陷：资格缺失、星号不响应、算术错误、时间矛盾、围标文本痕迹）+ 数据台账
- M2 解析层：双侧解析器 → 采购需求参数卡 + 投标响应参数卡，回归测试
- M3 知识与规则：法规三层知识库 + 符合性矩阵引擎（资格比对/星号核验/算术复核/时间逻辑），依据关联
- M4 LLM 兜底 + 内置基准：解析 F1 ≥0.95、误报 0
- M5 编排与交付：CLI + docx 评审报告 + 围标图谱 HTML + Web 面板（0 外链）
- M6 脱敏发布 GitHub + 收尾固化（tag/release/topics）
